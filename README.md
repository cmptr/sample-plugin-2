# Cmptr Sample

A tiny sandbox used to exercise directory submission, review, and lifecycle flows end to end. It is intentionally minimal and not meant for real use.

## What it does

- Adds a ribbon icon that shows a configurable greeting.
- Adds two commands: open a greeting modal, and insert the greeting at the cursor.
- Adds a settings tab where the greeting text can be changed.

## Why it exists

Submitting, reviewing, renaming, archiving, and restoring an entry all need a real repository with real releases behind it. This one exists so those flows can be tested without touching anyone's actual work.
